## How it works

```
Dolibarr page (index.php)
  │  performSsoLogin()  ── HMAC token ──▶  Cypht cypht_login()
  │
  └─ <iframe> ──▶ public/index.php  (the built Cypht app)
                      │
                      ├─ Custom_Auth          verifies the HMAC token
                      ├─ Custom_Session       own session files
                      ├─ Custom_User_Config   reads/writes llx_cyphtwebmail_userconfig
                      └─ dolibarr_contacts    HTTP ──▶ bridge/contacts.php
```

**Single sign-on:** Dolibarr mints a 60-second HMAC token, `Custom_Auth` verifies it.

**Database config:** No password login under SSO, so `Custom_User_Config` stores settings in the database.

**Iframe isolation:** Keeps Cypht and Dolibarr's CSS/session models separate. URL sync enables reload and bookmarking.

**Build steps:**
1. Composer installs Cypht and dependencies
2. Module sets are copied from `cypht/modules/` into the vendored Cypht
3. `config_gen.php` compiles module sets into `dynamic.php`
4. Output published to `public/` with paths made relocatable

## Adding a new Cypht module set

A module set is Cypht's plugin format. See [Cypht docs](https://cypht.org/modules/) and 
`vendor/jason-munro/cypht/modules/` for examples.

### 1. Create the folder

```
cypht/modules/<your_module>/
```

Mirror the native layout exactly:

| File | Required | Purpose |
|---|---|---|
| `README.md` | recommended | what the module set does |
| `setup.php` | **yes** | registers handlers/outputs and returns input filters |
| `modules.php` | **yes** | the handler and output classes |
| `hm-<name>.php` | optional | library classes, required from `modules.php` |
| `site.css`, `site.js` | optional | concatenated into the build |

Good models to copy: `gmail_contacts` (smallest complete set), `ldap_contacts`
(a full contact source), `site` (overriding shipped behaviour).

### 2. Register it

Add to `CYPHT_MODULES` in `class/install/environment.class.php`:

```php
'CYPHT_MODULES' => 'core,contacts,dolibarr_contacts,<your_module>,imap,smtp,...',
```

**Order matters:** modules must come after dependencies (e.g., contact sources after `contacts`).

### 3. Build

Press Generate in the web UI or run `php scripts/build.php`. The installer copies
files from `cypht/modules/` into vendored Cypht—no code changes needed.

### 4. Verify

The build log lists installed modules. Check `vendor/jason-munro/cypht/modules/<your_module>/` exists.

## Adding a new bridge endpoint

Bridge endpoints are HTTP callbacks from Cypht into Dolibarr. See `bridge/contacts.php`.

A bridge endpoint:
1. Defines `NOLOGIN` constants and loads `main.inc.php`
2. Verifies HMAC token with a purpose tag (prevents replay):
   ```php
   $expected = hash_hmac('sha256', $login.'|'.$timestamp.'|contacts', $secret);
   ```
3. Enforces 60-second replay window
4. Returns JSON with `Cache-Control: no-store`

Use `GETPOST('login', 'aZ09arobase')` and `GETPOST('token', 'aZ09')` for input filters.

Integration: 
1. Create `class/integration/YourSource.php` with static `resolveBridgeUrl()`
2. Add env key to `buildEnvOverrides()` in `class/install/environment.class.php`
3. Read it in module set with `Hm_Environment::get('YOUR_KEY')`

## Conventions and workflow

### Conventions

- Follow Dolibarr's style: tabs, `array()`, `dol_escape_htmltag()` on output, `GETPOST()` with explicit filter
- Use `cypht/modules/` to add a module or edit/patch a cypht module.
- Copy query patterns from Dolibarr core (module keys ≠ permission names)
- One concern per class
- No code in strings—PHP, JS, CSS in separate files

### Working on Cypht modules

Module sets in `cypht/modules/` are copied into vendored Cypht at build time. They're never loaded by Dolibarr.

### Testing checklist

- [ ] Build completes, `public/` refreshed
- [ ] SSO logs in without a Cypht login screen
- [ ] Mail lists and messages load
- [ ] Contacts appear under Personal Addresses with source `dolibarr`
- [ ] Compose autocomplete finds a Dolibarr contact
- [ ] Reload keeps the current Cypht page
- [ ] Deleting a test user removes their `llx_cyphtwebmail_userconfig` row
